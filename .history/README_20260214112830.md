# GlobalFruit — WhatsApp Landing для TikTok рекламы

Одностраничный сайт-подложка: считывает UTM из URL и формирует ссылку WhatsApp с тегом.

## Как работает

```
TikTok → globalfruit.kz?utm=orng → кнопка WhatsApp → wa.me/...?text=(tttorng) ДД! Хочу получить прайс...
```

## Приоритет UTM параметров

| Приоритет | Параметр        | Описание                  |
|-----------|-----------------|---------------------------|
| 1         | `ad_name`       | Имя объявления TikTok     |
| 2         | `utm_content`   | Имя креатива              |
| 3         | `utm`           | Ручной параметр           |
| 4         | `campaign_name` | Имя кампании              |
| —         | *(пусто)*       | По умолчанию: `ttt1`      |

## TikTok Pixel

Открой `index.html`, найди строку:
```js
// ttq.load('YOUR_PIXEL_ID');
```
Раскомментируй и замени `YOUR_PIXEL_ID` на свой Pixel ID.

## Настройка домена

В DNS `globalfruit.kz` добавь **одну** из конфигураций:

**Вариант A — CNAME:**
```
CNAME  @  →  USERNAME.github.io
```

**Вариант B — A-записи:**
```
A  @  →  185.199.108.153
A  @  →  185.199.109.153
A  @  →  185.199.110.153
A  @  →  185.199.111.153
```
